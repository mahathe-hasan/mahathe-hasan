- 💻 **Skills & Background:** Web Design & Development for Freelancing (Level 3) & Android Mobile App Development (Level 4)

- 👯 **Open to Collaborate On:** Frontend Web Development & Creative UI Projects
- 💬 **Ask Me About:** HTML5, CSS3, JavaScript, Bootstrap, Responsive Design, and Android Basics
